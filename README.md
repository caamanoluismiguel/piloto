# Piloto interior 106

Galería del piloto de reconstrucción interior del Edificio 106 (Isthmus, Panamá): recorrido navegable con splats, nube de puntos contra fotos, planta y cortes, y modelo paramétrico. Unidades de reconstrucción, sin escala en metros. Uso interno del equipo.

Generado el 11 de octubre de 2026. Proceso documentado en el repo `edificio-106`, `docs/analisis/PILOTO-INTERIOR.md` y `EXPERIMENTOS-PILOTO.md`.
